# てこマスター（LEVER MASTER）⚖️

**きょり × 重さ で、てこをつり合わせよう。**
小学6年 理科「てこのはたらき」を、実験 → 問題 → 対戦 の3ステップで遊びながら学べる教材ゲームです。

| 配信先 | URL | 用途 |
| --- | --- | --- |
| GitHub Pages（本体） | [atariryuma.github.io/lever-master](https://atariryuma.github.io/lever-master/) | PWA・オフライン対応のフル機能版 |
| GAS Web アプリ（ミラー） | [script.google.com/.../exec](https://script.google.com/macros/s/AKfycbz_PW1DWZy3svW9yOus-wvuN4et-666Ees99J3Kgjj7ZYxv0VSwGxcl0rVJzriNsR6i6w/exec) | Google サイト / Classroom への埋め込み用 |

## 3つのモード

| モード | ねらい | 内容 |
| --- | --- | --- |
| 🧪 **じっけん** | しくみを調べる | 10g・20g・30g のおもりを自由につるし、左右の「はたらき（きょり×重さ）」を式とバーでその場で確認。式をかくしたり、手でささえたりもできる |
| 🧩 **もんだい** | 予想してたしかめる | 全16問・5章（おなじ重さ → 重さがちがう → 2つ以上 → 両がわ → 頭で計算）。てこを手でささえたままつるし、「手をはなす」で結果を見る。ためした回数で ★1〜3 |
| ⚖️ **たいせん** | 計算を使いこなす | 2〜4人（ひと・CPU を自由に組み合わせ）。自分のおもりをつるし、1つだけ動かしてつり合わせる。かたむけたらアウト。外側ほど高得点だがむずかしい |

### たいせんのルール
1. **つるす** … 自分のおもり（10g）を1つつるす
2. **うごかす** … どれか1つだけ動かしてよい（今つるした場所のおもりは×、となりの場所へは×。左1⇔右1 もとなり）
3. **はなす** … かたむいたらアウト（てこはそのターンの前にもどる）

全員がおもりを使い切ったら、生き残りのうち **自分のおもりのはたらきの合計** が一番大きい人の勝ち。最後の1人になっても勝ち。
CPU は「やさしい・ふつう・つよい」の3段階。準備画面で「つり合うヒント（✓表示）」をオンにすると低学年や導入にも使えます。

## 特長

- **3D のてこ** … Three.js で描いたネオン調の実験室。うではバネのように傾き、おもりは振り子のようにゆれ、手をはなすと「つり合い→緑」「かたむき→重いほうが赤」に光る。WebGL が使えない端末では自動で 2D 表示に切りかわる（`?2d` で 2D を強制）
- **完全オフライン対応（PWA）** … Three.js とフォントも同梱し、外部CDNに依存せず、初回アクセス後はネットなしで動作。ホーム画面に追加するとアプリのように使えます
- **タブレット・PC・スマホ対応** … タップでもドラッグでも操作でき、横向き・縦向きどちらでもレイアウトが調整されます
- **だれでも使いやすく** … プレイヤーは色＋記号（●▲■◆）で区別、キーボード操作（Tab・矢印・Enter）、読み上げ（aria-live）、動きを減らす設定に対応
- **音は Web Audio で合成** … 効果音・BGM（初期はOFF）は「せってい」から切り替え

## 開発

```bash
npm install
npm run check   # ESLint + テスト
python3 -m http.server 8080   # http://localhost:8080 で確認
```

構成や設計は [DEVELOPMENT.md](DEVELOPMENT.md) を参照してください。

### デプロイ

編集するのは常に `src/` と `index.html` だけ。GAS 版は `src/` から自動生成するので二重管理はしません。

| コマンド | 内容 |
| --- | --- |
| `npm run build:gas` | `src/` から `gas/` を生成するだけ |
| `npm run push:gas` | 生成して Apps Script プロジェクトへ push |
| `npm run deploy:gas` | push して既存デプロイを更新（URL は変わらない） |
| `npm run deploy` | `git push`（GitHub Pages は Actions で自動デプロイ。反映後に `deploy:gas`） |

| 機能 | GitHub Pages | GAS |
| --- | --- | --- |
| ゲーム本体（3D / 2D） | ✅ | ✅（JS・CSS は GitHub Pages から読み込む） |
| Service Worker・オフライン | ✅ | ❌ 登録しない |
| PWA インストール | ✅ | ❌ |
| アイコン・フォント | ✅ | GitHub Pages を参照 |

GAS 版は GitHub Pages の本体を読み込むので、先に Pages を更新してから GAS をデプロイします。
リリース時は `sw.js` の `VERSION` を上げてください。
