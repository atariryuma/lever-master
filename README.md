# りかラボ（RIKA LAB）

単元ごとのゲーム：**てこマスター（LEVER MASTER）** ＋ **ふりこマスター（PENDULUM MASTER）**

> リポジトリ名・公開URLは配布ずみのリンクを切らないよう `lever-master` のまま

**きょり × 重さ で、てこをつり合わせよう。／ ふりこの長さ で、1往復の時間が決まる。**
小学6年 理科「てこのはたらき」と小学5年 理科「ふりこの運動」を、実験 → 問題 → 対戦 の3ステップで遊びながら学べる物理シミュレーション教材ゲームです。
ホーム画面で単元（6年 てこ／5年 ふりこ）を切りかえます。

## 6年 てこ：3つのモード

| モード | ねらい | 内容 |
| --- | --- | --- |
| **じっけん** | しくみを調べる | 10g・20g・30g のおもりを自由につるし、左右の「はたらき（きょり×重さ）」を式と**面積図**（横＝きょり、縦＝重さ）でその場で確認。水平のまま静まるとチャイム。おもりはドラッグで動かし、てこの外へ出すとはずれる。式をかくしたり、手でささえたりもできる |
| **もんだい** | 予想してたしかめる | 全16問・5章（おなじ重さ → 重さがちがう → 2つ以上 → 両がわ → 頭で計算）。**傾かない図の上でおもりを置いて予想**し、さわらずに少し待つ（または「3Dでたしかめる」）と 3D のてこが手をはなれて答え合わせ。水平のまま静まればクリア。はずれたら図にもどって考え直す。ためした回数で ★1〜3。章クリア・全クリアの演出つき |
| **たいせん** | 計算を使いこなす | 2〜4人（ひと・CPU を自由に組み合わせ）。自分のおもりをつるし、1つだけ動かしてつり合わせる。かたむけたらアウト。外側ほど高得点だがむずかしい |

### たいせんのルール
1. **つるす** … 自分のおもり（10g）を1つつるす
2. **うごかす** … どれか1つだけ動かしてよい（ドラッグで。動かしなおしもOK、てこの外へ出すと元にもどる）。つかんだおもりの**下にぶら下がっているおもりも道づれ**でいっしょに動く（今つるした場所のおもりは×、となりの場所へは×。左1⇔右1 もとなり）
3. **けってい** … 水平のまま静まって 2 秒キープすると自動で決定（ボタンでもOK）。かたむいていたらアウト（てこはそのターンの前にもどる）。持ち時間（なし・30・60・90・120秒、標準90秒）を使い切ると、その形のまま自動で判定（まだつるしていなければアウト）

全員がおもりを使い切ったら、生き残りのうち **自分のおもりのはたらきの合計** が一番大きい人の勝ち。最後の1人になっても勝ち。
てこは、つるしたり動かしたりするたびにその場で傾きます。ターン開始の演出、ドラムロールからの SAFE!/OUT!!、残り時間の心音、FINAL ROUND で速くなる BGM など、対戦ゲームとしての演出つき。
はじめての対戦の前には、絵で4ステップの「あそびかた」が出る（「？」からいつでも見られる）。自分の番には「1 つるす → 2 うごかす → 3 けってい」のどこにいるかを表示し、おもりをつかむと動かせない「となり」に ✕ が出る。
CPU は「やさしい・ふつう・つよい」の3段階。人のように候補の場所を見くらべながら考え、つよいほどじっくり考える（「はやおくり」で短縮）。準備画面で「つり合うヒント（✓表示）」をオンにすると低学年や導入にも使えます。

## 5年 ふりこ：3つのモード

| モード | ねらい | 内容 |
| --- | --- | --- |
| **じっけん** | 条件をそろえて調べる | A（50cm・10g・20°）に対して、B は「変える条件」（長さ／重さ／ふれはば）を1つだけ変える（ほかはそろえる＝条件制御）。おもりを横にドラッグして持ち上げ、はなすと2つが同時にふれる。**10往復の時間を実測**して「同じ／どちらがはやい」を表示。結果は「きろく」の表にたまる |
| **もんだい** | 予想してたしかめる | 全17問・5章（長さがちがう → 重さは関係ある？ → ふれはばは？ → 正しい実験は？ → ちょうどの時間）。図の上で予想（どっちがはやい／正しい実験はどれ／何cmにする）をえらび、「3Dでたしかめる」で手をはなして10往復を数える。合っていればクリア。ためした回数で ★1〜3 |
| **たいせん「ジャスト・タイム」** | 長さと時間の関係を使いこなす | 2〜4人（ひと・CPU）。「10往復で 16.0秒」のような目標に合わせて、順番にふりこの長さ（10〜100cm）を決め、全員いっせいにはなす。実測した時間が目標に近いほど高得点（PERFECT ±0.1秒 100点 〜 MISS 10点）。重さ・ふれはばも変えられるが時間には関係ない（わな）。「長さ → 時間」のグラフ（ヒントの表の点、前のラウンドで全員が実測した点、ねらいの線）を手がかりに、あいだの長さを予想する。長さはみんなにないしょで決め、OPEN! で一斉に公開、3・2・1 で同時にはなし、共通のストップウォッチがねらいの時刻でフラッシュ。ラウンドごとの結果表、合計点で勝負 |

ふりこの時間は長さだけで決まる（T = 2π√(L/g)）。教科書どおり「ふれはばを変えても時間は変わらない」ようにしてあります。

## 特長

- **本物の物理** … てこは剛体の回転運動（おもりのトルク・慣性モーメント・支点下の重心による復元・減衰・ストッパー）、ふりこは単振動を、固定きざみで数値積分。つるした反動でゆれ、差が大きいほど大きくかたむき、ふりこの10往復はシミュレーションを実測する（`engine/physics.js`）
- **3D と図（2D）** … Three.js で描いたネオン調の実験室。じっけんでは「図で見る」で、もんだいでは予想のときに、教科書のような 2D 図を使い、支点からのきょりをものさしで表示。WebGL が使えない端末では自動で 2D（`?2d` で強制）
- **ゲームとしての音と演出** … BGM はメニュー・学習・対戦の3曲（対戦は試合の進み具合で速くなる）。効果音・BGM は「せってい」の音量スライダーで調整（0 で OFF）
- **完全オフライン対応（PWA）** … Three.js とフォントも同梱し、外部CDNに依存せず、初回アクセス後はネットなしで動作。ホーム画面に追加するとアプリのように使えます
- **タブレット・PC・スマホ対応** … タップでもドラッグでも操作でき、横向き・縦向きどちらでもレイアウトが調整されます。スマホの「戻る」はアプリの「もどる」と同じ（対戦中は確認してから）
- **だれでも使いやすく** … プレイヤーは色＋記号（●▲■◆）で区別、キーボード操作（Tab・矢印・Enter）、読み上げ（aria-live）、動きを減らす設定に対応
- **音は Web Audio で合成** … 音声ファイル不要・オフラインで鳴る
- **アイコンは SVG** … 絵文字は端末ごとに見た目が変わるので使わず、専用のアイコンを使用

## 開発

```bash
npm install
npm run check   # ESLint + テスト
python3 -m http.server 8080   # http://localhost:8080 で確認
```

構成や設計は [DEVELOPMENT.md](DEVELOPMENT.md) を参照してください。

### デプロイ

編集するのは常に `src/` と `index.html` だけ。GAS 版は `src/` から自動生成するので二重管理はしません。

| コマンド | 内容 |
| --- | --- |
| `npm run build:gas` | `src/` から `gas/` を生成するだけ |
| `npm run push:gas` | 生成して Apps Script プロジェクトへ push |
| `npm run deploy:gas` | push して既存デプロイを更新（URL は変わらない） |
| `npm run deploy:gas:school` | 学校版（naha-okinawa.ed.jp）を更新。学校のアカウントで `clasp login --user school` しておく |
| `npm run deploy` | `git push`（GitHub Pages は Actions で自動デプロイ。反映後に `deploy:gas`） |

| 機能 | GitHub Pages | GAS |
| --- | --- | --- |
| ゲーム本体（3D / 2D） | ✅ | ✅（JS・CSS は GitHub Pages から読み込む） |
| Service Worker・オフライン | ✅ | ❌ 登録しない |
| PWA インストール | ✅ | ❌ |
| アイコン・フォント | ✅ | GitHub Pages を参照 |

GAS 版は GitHub Pages の本体を読み込むので、先に Pages を更新してから GAS をデプロイします。
リリース時は `sw.js` の `VERSION` を上げてください。
